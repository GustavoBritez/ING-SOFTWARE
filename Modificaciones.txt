La única manera de hacer esto es creando los métodos ExecuteNonReader utilizando consultas parametrizadas ósea *SQLParams*

*public void ExecuteNonQuery(string stringQuery, params SqlParameter[] parametros)*


*public DataTable ExecuteReader(string stringQuery, params SqlParameter[] parametros)*

En los diagramas debemos modificar estos métodos para que queden igual al código, nosotros mandábamos solo stringQuery como parámetro pero eso es vulnerable a ataques SQLInjection


Login

1. Usuario ingresa: NombreDeUsuario (string) + Contraseña plana (string)
   ↓
2. DAL busca en BD el usuario por NombreDeUsuario
   ↓
3. Si NO existe → Login fallido
   Si existe → obtener usuario con contraseña HASHEADA
   ↓
4. BLL compara:
   - Contraseña plana ingresada vs Contraseña hasheada en BD
   - BCrypt.Verify(contraseña_plana, contraseña_hasheada_bd)
   ↓
5. Si coinciden → Login exitoso
   Si no coinciden → Login fallido

El método login devuelve TRUE or FALSE es bool 
public bool Login(string nombreDeUsuario, string contraseñaPlana)
