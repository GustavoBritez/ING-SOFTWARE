# ING-SOFTWARE


Problema Actual:
Los profesionales de salud (Médicos y Nutricionistas) cargan datos de pacientes en planillas Excel desvinculadas, sin visibilidad de evoluciones temporales. 

El Director Médico no puede responder preguntas como "¿Cuántos pacientes están en riesgo cardiovascular crítico?" sin invertir horas compilando información. Las decisiones clínicas se basan en fotografías puntuales de datos, no en tendencias.

Solución Propuesta:
Desarrollar una aplicación integrada que permita:
1. Médicos y Nutricionistas carguen datos clínicos periódicos (peso, glucosa, colesterol, análisis bioquímicos)
2. El sistema genere automáticamente gráficos de evolución temporal que visualicen tendencias
3. Se emitan alertas cuando valores superen umbrales críticos
4. El Director Médico acceda a reportes consolidados (matriz de riesgo, diagnósticos prevalentes, adherencia por profesional)

Módulos Principales:
- Gestión de Pacientes y Perfiles
- Carga de Datos Clínicos (Médico y Nutricionista)
- Motor de Gráficos y Alertas
- Dashboard Analítico para Director Médico

Beneficio Esperado:
Decisiones clínicas informadas por datos, reducción de tiempo en análisis manual, identificación proactiva de pacientes en riesgo, evaluación objetiva del desempeño profesional.
